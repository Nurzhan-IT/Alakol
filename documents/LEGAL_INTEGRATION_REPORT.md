## ⚡ JAVASCRIPT ФУНКЦИОНАЛЬНОСТЬ

### Класс LegalValidation:
```javascript
class LegalValidation {
    // Валидация чекбоксов в реальном времени
    validateCheckbox(checkbox)
    
    // Валидация всей формы
    validateForm(form)
    
    // Отслеживание просмотров документов
    trackLegalDocumentViews()
    
    // Сохранение/восстановление состояния
    saveUserConsents()
    restoreUserConsents()
}
```

### Основные функции:
1. **Валидация в реальном времени** - проверка при изменении чекбоксов
2. **Предотвращение отправки** - блокировка форм без согласий
3. **Визуальная обратная связь** - цветовая индикация состояний
4. **Автоматическое сохранение** - localStorage для необязательных согласий
5. **Аналитика** - отслеживание просмотров документов
6. **Доступность** - поддержка клавиатурной навигации
