### 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ ИНТЕГРАЦИИ

#### Архитектура HMS Alakol:
- **Django 4.2.2** с базой данных PostgreSQL
- **Система платежей Robokassa** с соответствием PCI DSS
- **Шестиэтапный процесс бронирования HMS**
- **Схема оплаты 10% предоплата + 90% при заселении**
- **OTP система верификации**
- **SSL/TLS шифрование и SHA256 подписи**
- **Часовой пояс Kazakhstan/Astana (UTC+5)**
- **Семь специализированных модулей:** hotel, booking, userauths, user_dashboard, robokassa, search, addon
- **Многоязычная поддержка** и автоматическое истечение сессий (10 минут для неоплаченных бронирований)

#### Обработка персональных данных:
- **Категории данных:** Аккаунт (User model), Бронирование (Booking model), Платежи, Технические, Поведенческие
- **Цели обработки:** Предоставление услуг бронирования, выполнение договорных обязательств, обеспечение безопасности
- **Передача третьим лицам:** Партнерские отели, Robokassa, IT-подрядчики, государственные органы РК
- **Сроки хранения:** 5 лет для данных бронирования, 1 год для технических данных

#### Правила оплаты и возврата:
- **Инновационная схема "10% + 90%"** с предоплатой при бронировании
- **Методы оплаты:** Банковские карты, электронные кошельки, интернет-банкинг, мобильные платежи
- **Условия возврата:** 0% при добровольной отмене, 100% при форс-мажоре
- **Безопасность:** PCI DSS стандарты через Robokassa
