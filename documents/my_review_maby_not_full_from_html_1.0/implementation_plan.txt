1. АНАЛИЗ ПРОЕКТА НА ОСНОВЕ КОДА

1.1. Выявленные особенности системы:

ТЕХНИЧЕСКАЯ АРХИТЕКТУРА:
- Django 3.2.18 с PostgreSQL
- Модульная структура: hotel, booking, userauths, robokassa
- Поддержка трех языков: казахский, русский, английский
- Интеграция с платежной системой Robokassa (Казахстан)

БИЗНЕС-МОДЕЛЬ:
- Посредническая платформа бронирования отелей
- Схема оплаты: 10% предоплата + 90% при заселении
- Динамическое ценообразование
- Система отмены с различными условиями

ПЕРСОНАЛЬНЫЕ ДАННЫЕ:
- Базовые данные пользователя: ФИО, email, телефон, пол
- Данные профиля: страна, город, адрес
- Данные бронирования: даты, количество гостей, предпочтения
- Технические данные: IP-адрес, user-agent, cookie

ПЛАТЕЖНАЯ СИСТЕМА:
- Основной провайдер: Robokassa
- Поддержка карт Visa, MasterCard, МИР
- Электронные кошельки и банковские переводы
- Тестовый и продакшн режимы

1.2. Выявленные юридические риски:

ВЫСОКИЙ РИСК:
- Отсутствие документов о защите персональных данных
- Неопределенность условий отмены бронирования
- Отсутствие четких правил возврата средств
- Неурегулированные вопросы ответственности

СРЕДНИЙ РИСК:
- Необходимость соответствия требованиям РК по туристическим услугам
- Валютное законодательство при международных платежах
- Налоговые обязательства по НДС

НИЗКИЙ РИСК:
- Техническая безопасность данных (использует HTTPS)
- Соответствие требованиям доступности
