1.1. HMS Alakol представляет собой современную веб-платформу для бронирования отелей, построенную на технологической основе Django 4.2.2 (Python web framework) с использованием защищенной базы данных PostgreSQL и официально интегрированной платежной системы Robokassa.

1.3. Архитектура HMS включает семь специализированных модулей: hotel (управление отелями), booking (бронирование), userauths (аутентификация пользователей), user_dashboard (личный кабинет), robokassa (платежная система), search (поиск отелей), addon (дополнительные функции).

2. КАТЕГОРИИ ПЕРСОНАЛЬНЫХ ДАННЫХ

2.1. Данные учетной записи пользователя (модель User HMS):
- адрес электронной почты (используется как username, уникальный идентификатор)
- пароль (в зашифрованном виде через Django 4.2.2)
- имя пользователя (username)
- полное имя (full_name)
- номер телефона (phone) с кодом страны
- пол (gender) - мужской/женский
- страна проживания (country)
- город проживания (city)
- адрес места жительства (address)
- фотография профиля (image)
- OTP код для верификации безопасности
- статус верификации учетной записи (verified)
- данные электронного кошелька (wallet) для бонусных программ

2.2. Данные бронирования (модель Booking HMS):
- полное имя гостя (full_name)
- контактный email гостя
- код страны и номер телефона (country_code, phone)
- выбранный отель и тип номера
- конкретные забронированные номера
- даты заезда и выезда (check_in_date, check_out_date)
- количество дней проживания (total_days)
- количество взрослых и детей (num_adults, num_children)
- данные о выборе номера (selection_data) в формате JSON
- уникальный идентификатор бронирования (booking_id)
- идентификатор транзакции Robokassa (robokassa_inv_id)
- финансовые данные: сумма до скидки, итоговая сумма, экономия
- статусы заселения и выселения (checked_in, checked_out)
- статус оплаты и активности бронирования
- примененные купоны и скидки

2.3. Платежная информация (через интеграцию Robokassa):
- данные о транзакциях и платежах (без сохранения номеров карт)
- идентификаторы платежей и чеков
- история финансовых операций
- информация о возвратах и чарджбэках
- данные для налогового учета

2.4. Технические данные:
- IP-адрес устройства пользователя
- данные файлов cookie и сессий
- информация о браузере и операционной системе
- время посещений и длительность сессий
- логи действий пользователя в системе HMS
- данные автоматического удаления истекших сессий

2.5. Поведенческие данные:
- история поиска отелей и фильтрации
- предпочтения в выборе номеров и отелей
- частота использования различных функций сервиса
- аналитика взаимодействия с интерфейсом
- статистика использования мобильной и веб-версий
- данные для персонализации предложений
