1. ОБЩИЕ ПОЛОЖЕНИЯ

1.1. Настоящие Правила определяют порядок оплаты услуг бронирования отелей и условия возврата денежных средств при использовании системы eKol для региона Алаколь через веб-сайт [АДРЕС САЙТА].

1.2. Правила разработаны в соответствии с законодательством Республики Казахстан и являются неотъемлемой частью Публичной оферты на оказание услуг бронирования.

1.3. Используя сервис и производя оплату, Пользователь соглашается с настоящими Правилами в полном объеме.

1.4. Система eKol поддерживает мультиязычность (казахский, русский, английский языки) и работает в временной зоне Kazakhstan/Astana (UTC+5).

1.5. Архитектура системы включает семь специализированных модулей: hotel (управление отелями), booking (бронирование), userauths (аутентификация), user_dashboard (личный кабинет), robokassa (платежи), search (поиск), addon (дополнительные функции).

2. СПОСОБЫ ОПЛАТЫ

2.1. Оплата услуг осуществляется исключительно через официально интегрированную платежную систему Robokassa

2.2. Все платежи обрабатываются в соответствии со стандартами безопасности PCI DSS.

2.3. Платежная информация (номера карт, пин-коды) не сохраняется на серверах нашей системы и обрабатывается исключительно платежной системой Robokassa.

3. СТРУКТУРА ПЛАТЕЖЕЙ

3.1. Гибкая схема оплаты системы eKol с переменным размером предоплаты:

3.1.1. Предоплата при подтверждении бронирования:
- размер: N% от общей стоимости проживания, где N может составлять 10%, 30%, 50%, 70% или 100%
- конкретный размер N% определяется политикой каждого отеля
- назначение: гарантия серьезности намерений и подтверждение бронирования
- включает: комиссию платформы eKol
- обработка: через интегрированную платежную систему Robokassa
- валюта: тенге (KZT) или другие доступные валюты
- срок оплаты: 10 минут с момента создания бронирования (автоматическое истечение при неоплате)

3.1.2. Доплата при заселении в отель:
- размер: оставшиеся (100% - N%) от общей стоимости проживания
- способ оплаты: непосредственно в отеле любым удобным способом
- валюта: согласно политике конкретного отеля
- момент оплаты: при заселении

3.1.3. Варианты схем оплаты в зависимости от политики отеля:
- При N = 10%: предоплата 10%, доплата при заселении 90%
- При N = 30%: предоплата 30%, доплата при заселении 70%
- При N = 50%: предоплата 50%, доплата при заселении 50%
- При N = 70%: предоплата 70%, доплата при заселении 30%
- При N = 100%: полная оплата при бронировании 100%, без доплаты

3.2. Дополнительные сборы и налоги:

3.2.1. НДС включен в указанную стоимость (при применимости).

3.2.2. Комиссия платформы включена в общую стоимость.

3.2.3. ВАЖНОЕ УВЕДОМЛЕНИЕ О ОКРУГЛЕНИЯХ: В связи с процентными вычислениями при расчете предоплаты, доплаты и возвратов средств, все денежные суммы могут округляться с погрешностью до 1 (одного) тенге в большую или меньшую сторону.

3.2.4. Комиссии платежных систем:
- при оплате банковскими картами комиссия не взимается с Пользователя
- комиссии электронных кошельков согласно тарифам соответствующих систем
- комиссии банковских переводов согласно тарифам банков

3.3. Курортный сбор (туристический налог):
- не включен в стоимость бронирования
- оплачивается отдельно при заселении в отель
- размер определяется местным законодательством

4. ПРОЦЕСС ОПЛАТЫ В СИСТЕМЕ eKol

4.1. Шестиэтапный процесс бронирования eKol:

4.1.1. Поиск отелей по городу, датам заезда/выезда, количеству гостей.
4.1.2. Выбор конкретного номера и просмотр детальной информации.
4.1.3. Автоматическая проверка доступности выбранных номеров.
4.1.4. Заполнение контактных данных гостя с OTP-верификацией.
4.1.5. Подтверждение условий и переход к оплате N% предоплаты.
4.1.6. Обработка платежа через Robokassa и получение подтверждения.

4.2. Технические особенности обработки платежей:

4.2.1. Использование защищенного соединения SSL/TLS.
4.2.2. Генерация цифровых подписей SHA256 для безопасности.
4.2.3. Автоматическое уведомление системы отеля о подтвержденном бронировании.
4.2.4. Мгновенная отправка подтверждения клиенту по email или SMS.
