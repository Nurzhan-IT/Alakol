3. CATEGORIES OF PERSONAL DATA
3.1. We process the following categories of personal data according to the eKol system User model:
3.1.1. Account data:

last name, first name, patronymic (full_name);
email address (email) - used as username, unique;
phone number (phone);
gender (gender) - male/female;
country and city of residence (country, city);
residential address (address);
password (in encrypted form);
profile photo (image);
OTP code for verification;
electronic wallet (wallet) - for future bonus programs;
verification status (verified).

3.1.2. Booking data according to the Booking model:

guest's full name (full_name);
guest's email (email);
country code (country_code);
phone number (phone);
selected hotel (hotel);
room type (room_type);
specific rooms (room) - many-to-many relationship;
selection data (selection_data) - JSON field;
check-in and check-out dates (check_in_date, check_out_date);
number of days (total_days);
number of adults and children (num_adults, num_children);
check-in/check-out statuses (checked_in, checked_out);
unique booking ID (booking_id);
Robokassa transaction ID (robokassa_inv_id);
preferences and special requests.

3.1.3. Payment information:

bank card data (processed by Robokassa payment system);
payment and transaction information;
payment identifiers;
amount before discount (before_discount);
total amount (total);
savings amount (saved);
payment status (payment_status);
IMPORTANT ROUNDING NOTICE: Due to percentage calculations when calculating advance payments, additional payments, and refunds, all monetary amounts may be rounded with an error of up to 1 (one) tenge in either direction;
applied coupons (coupons).

3.1.4. Technical data:

browser and device information;
cookie files;
user visit and action logs;
session times;
system fields: booking activity (is_active), creation time (created_at), expiration time (expires_at).

3.1.5. Behavioral data:

hotel search history;
room selection preferences;
service usage frequency;
eKol system interface interaction analytics.

4. PURPOSES OF PERSONAL DATA PROCESSING
4.1. Personal data is processed for the following purposes:
4.1.1. Providing booking services:

processing booking requests through the eKol system booking module;
confirming and modifying bookings (modification possible only 15 days before check-in);
communication with hotels for accommodation organization.

4.1.2. Ensuring eKol system operation:

user registration and authentication through the userauths module;
OTP system for verification;
interface personalization;
security provision;
management through the user_dashboard module.

4.1.3. Communications:

sending booking confirmations;
informing about order changes;
technical support in Kazakh, Russian, and English languages;
marketing messages (with consent).

4.1.4. Analytics and service improvement:

analyzing eKol system usage through search and addon modules;
functionality improvement;
statistical research.

4.1.5. Compliance with legal obligations:

fulfilling RK legislation requirements;
fraud prevention;
dispute resolution.

5. METHODS OF PERSONAL DATA PROCESSING
5.1. Personal data processing is carried out using automation tools and without their use.
5.2. Processing methods include: collection, systematization, accumulation, database storage; clarification, modification, use; distribution, transfer, anonymization, blocking, deletion.
6. PERSONAL DATA PROCESSING TERMS
6.1. Personal data is processed for the following terms:

6.1.1. Account data - until submission of consent withdrawal request or account deletion.
6.1.2. Booking data - for 5 years after completion of the last booking for accounting reporting and dispute resolution purposes.
6.1.3. Technical data - for 1 year from the last visit to the eKol system.
6.1.4. Payment information - in accordance with RK financial legislation requirements and Robokassa policy.
6.1.5. Unpaid bookings - automatically deleted 10 minutes after payment deadline expiration.
