## 🚀 Инструкции по применению

### 1. Резервное копирование текущего окружения
```bash
pip freeze > current_environment_backup.txt
```

### 2. Применение оптимизации
```bash
# Удаляем старые пакеты (опционально)
pip uninstall -r requirements.txt -y

# Устанавливаем только необходимые
pip install -r requirements_optimized.txt
```

### 3. Проверка работоспособности
```bash
# Проверка Django
python manage.py check

# Проверка статических файлов
python manage.py collectstatic --dry-run

# Проверка миграций
python manage.py migrate --check

# Запуск сервера разработки
python manage.py runserver
```

### 4. Окончательное применение (если все работает)
```bash
# Заменяем оригинальный файл
copy requirements_optimized.txt requirements.txt
```

### 5. Восстановление (при проблемах)
```bash
# Восстановление из резервной копии
pip install -r requirements_original_20250624_135736.txt
```
