1. General Technical Requirements

1.1. System Requirements for Platform Operation:

  • Stable internet connection (minimum 10 Mbps)
  • Modern web browser (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
  • JavaScript and cookies support
  • Screen resolution not less than 1024x768 pixels

1.2. Platform Technical Specifications:

Backend Django 4.2.2 (Python web framework)
Database PostgreSQL
Payment System Robokassa.kz
Multilingual Support Kazakh, Russian, English languages
Time Zone Asia/Yekaterinburg (UTC+5)
Encryption SSL/TLS (HTTPS)

2. Hotel Profile Registration and Setup

2.1. Registration Procedure:

  1. Creating an account on the platform through web interface
  2. Email address verification (mandatory)
  3. Mobile phone confirmation via SMS/OTP
  4. Providing documents for hotel verification

2.2. Required Data for Hotel Profile (Hotel Model):

Field Description Limitations
name Hotel name Maximum 100 characters
description Hotel description Detailed text description
image Main hotel image Formats: JPG, PNG, maximum 5MB
address Full address Maximum 200 characters
mobile Mobile phone Maximum 20 characters, format: +7XXXXXXXXXX
email Hotel email Working email for guest communication
check_in_time Check-in time Format: HH:MM (e.g., 14:00)
check_out_time Check-out time Format: HH:MM (e.g., 12:00)

3. Room Inventory Management

3.1. Room Types (RoomType Model):

  • type: Room type name - maximum 120 characters
  • price: Base price per night - in tenge, format: XXXXX.XX
  • dynamic_pricing: Dynamic pricing - JSON format for special dates
  • number_of_beds: Number of beds - integer
  • room_capacity: Room capacity - maximum number of guests
  • room_size: Room size - area in square meters

3.2. Individual Rooms (Room Model):

  • room_number: Room number - unique within the hotel
  • is_available: Booking availability - boolean
  • room_type: Connection to room type - mandatory relationship

3.3. Additional Room Information:

  • Room type description (RoomTypeDescription)
  • Room image gallery (RoomTypeGallery) - up to 10 photos
  • Amenities list (RoomTypeFeatures) - icons and names
  • Detailed characteristics (RoomTypeFeaturesDetailed)

4. Pricing System

4.1. Base Pricing:

  • Setting price per night for each room type
  • Prices specified in Kazakhstani tenge (KZT)
  • Ability to set different prices for weekdays and weekends

4.2. Dynamic Pricing (JSON Format):

{
  "2025-07-01": 25000,
  "2025-07-02": 30000,
  "2025-12-31": 50000,
  "weekend_multiplier": 1.2,
  "holiday_multiplier": 1.5
}

4.3. Pricing Recommendations:

  • Consider seasonality and local holidays
  • Set competitive prices
  • Regularly analyze and adjust prices
  • Use discounts and special offers

5. Robokassa Payment System Integration

5.1. Payment Workflow:

  1. Customer pays 10% of total cost through Robokassa
  2. Platform receives prepayment and confirms booking
  3. Hotel receives information about confirmed booking
  4. Upon check-in, customer pays remaining 90% at the hotel

5.2. Integration Settings:

  • Support for test and live Robokassa modes
  • Automatic generation of secure SHA256 signatures
  • Payment lifetime: 10 minutes from creation
  • Supported currencies: KZT (tenge)

5.3. Payment Notification Processing:

  • ResultURL: automatic payment confirmation
  • SuccessURL: redirect after successful payment
  • FailURL: unsuccessful payment handling
  • All notifications processed in real-time

6. Booking Management

6.1. Booking Information (Booking Model):

  • Guest Data: Full name, email, phone, country code
  • Stay Information: check-in/check-out dates, number of days
  • Guest Count: adults and children separately
  • Selected Rooms: rooms and room type
  • Financial Information: total amount, prepayment, additional payment

6.2. Booking Statuses:

Status Description
initiated Created, awaiting payment
paid Paid, confirmed
pending In processing
cancelled Cancelled
failed Payment error
refunded Refunded

6.3. Automated Processes:

  • Sending notifications to hotel for new bookings
  • Automatic cancellation of unpaid bookings after 10 minutes
  • Email notifications to customers about booking status
  • Data synchronization with hotel system

7. Technical Support and API

7.1. Administrator Web Interface:

  • Access through Django admin panel
  • Management of all hotel and room aspects
  • Viewing and managing bookings
  • Analytics and reporting

7.2. API Capabilities (for advanced users):

  • REST API for automatic data updates
  • Webhooks for receiving booking notifications
  • PMS (Property Management System) integration
  • Data export in various formats

7.3. Monitoring and Logging:

  • All operation logs maintained automatically
  • Real-time room availability monitoring
  • Problem tracking and automatic resolution
  • Data backup every 24 hours

8. Security and Data Protection

8.1. Technical Security Measures:

  • All connections protected with SSL/TLS (HTTPS)
  • Personal data encryption in database
  • Regular system security updates
  • Protection against CSRF, XSS and SQL injections

8.2. Personal Data Processing:

  • Compliance with Republic of Kazakhstan Law "On Personal Data and Their Protection"
  • Minimization of processed data
  • Automatic deletion of outdated data
  • Logging access to personal data

8.3. Security Recommendations for Hotels:

  • Use complex passwords (minimum 8 characters)
  • Regular password changes (every 3 months)
  • Restrict access to administrative panel
  • Train staff on information security basics

9. Content Requirements

9.1. Images:

  • Formats: JPEG, PNG
  • Maximum size: 5MB per image
  • Recommended resolution: 1920x1080 pixels
  • Requirements: High-quality photos of rooms, territory, amenities

9.2. Text Content:

  • Detailed description of hotel and rooms
  • Current information about amenities and services
  • Stay rules and additional services
  • FAQ (frequently asked questions)

9.3. Multilingual Support:

  • Translation of main information into 3 languages: KZ, RU, EN
  • Use of Django translation system
  • Automatic user language detection
  • Ability to switch language anytime
