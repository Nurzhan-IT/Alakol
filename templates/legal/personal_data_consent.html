1.1. HMS Alakol Platform

HMS Alakol is a modern web platform for hotel booking, built on the Django 4.2.2 (Python web framework) technology base using a secure PostgreSQL database and officially integrated Robokassa payment system.

1.2. System Operation

The system operates in the Kazakhstan/Astana time zone (UTC+5) and supports multilingual functionality (Kazakh, Russian, English languages).

1.3. HMS Architecture

The HMS architecture includes seven specialized modules: hotel (hotel management), booking (reservation), userauths (user authentication), user_dashboard (personal cabinet), robokassa (payment system), search (hotel search), addon (additional functions).
