# Множественная загрузка изображений для HotelGallery

## Описание функциональности

Добавлена возможность загрузки нескольких изображений одновременно для галереи отелей (HotelGallery_Tab) в админ-панели Django. Поле для множественной загрузки отображается отдельно от записей HotelGallery, а существующие изображения показываются в виде кликабельных миниатюр.

## Новые возможности

### 1. Отдельное поле для множественной загрузки
- Поле "Загрузить несколько изображений" размещено отдельно в начале секции
- Улучшенный дизайн с градиентом и анимациями
- Четкие инструкции и ограничения
- Визуальная обратная связь при взаимодействии

### 2. Миниатюры существующих изображений
- Отображение записей HotelGallery в виде миниатюр 80x80px
- Hover-эффекты с увеличением и тенями
- Клик по миниатюре открывает полное изображение в новой вкладке
- Автоматическое кропирование изображений (object-fit: cover)

### 3. Множественная загрузка файлов
- Выбор нескольких изображений одновременно
- Поддержка форматов: JPG, PNG, WEBP
- Максимальный размер файла: 5MB
- Максимальное количество изображений на отель: 50

### 4. Drag & Drop поддержка
- Перетаскивание файлов прямо на поле загрузки
- Автоматическая фильтрация только изображений
- Визуальная обратная связь при перетаскивании

### 5. Предварительный просмотр
- Миниатюры загруженных изображений
- Отображение имени файла и размера
- Кнопка удаления для каждого изображения
- Анимированные превью с hover-эффектами

### 6. Валидация
- Проверка типа файла (только изображения)
- Ограничение размера файла (5MB)
- Ограничение общего количества изображений (50)
- Информативные сообщения об ошибках

## Как использовать

### 1. В админ-панели Django
1. Перейдите к редактированию отеля
2. В разделе "Галерея отеля" найдите отдельную секцию "Загрузка нескольких изображений" в верхней части
3. Нажмите на поле или перетащите файлы
4. Выберите несколько изображений
5. Просмотрите превью и при необходимости удалите ненужные
6. Сохраните изменения

### 2. Просмотр существующих изображений
1. Существующие изображения отображаются в виде миниатюр в таблице
2. Нажмите на любую миниатюру для просмотра полного изображения в новой вкладке
3. Используйте стандартные элементы управления Django для удаления изображений

### 3. Drag & Drop
1. Откройте файловый менеджер
2. Выберите несколько изображений
3. Перетащите их на поле "Загрузить несколько изображений"
4. Файлы автоматически добавятся к существующим

### 4. Удаление изображений
- **Новые изображения**: Нажмите на кнопку "×" в правом верхнем углу превью
- **Существующие изображения**: Используйте чекбокс "Удалить" в таблице

## Технические детали

### Валидация
```python
def clean_multiple_images(self):
    files = self.cleaned_data.get('multiple_images')
    for file in files:
        if file.size > 5 * 1024 * 1024:  # 5MB
            raise forms.ValidationError(f'Файл {file.name} слишком большой')
        if not file.content_type.startswith('image/'):
            raise forms.ValidationError(f'Файл {file.name} не является изображением')
    return files
```

### Сохранение файлов
```python
def save_formset(self, request, form, formset, change):
    # Обработка множественных файлов из поля #multiple_hotel_images
    if request.FILES and 'multiple_hotel_images' in request.FILES:
        hotel = form.instance
        files = request.FILES.getlist('multiple_hotel_images')
        for file in files:
            gallery_instance = HotelGallery(hotel=hotel, image=file)
            gallery_instance.save()
```

## Устранение неполадок

### Файлы не загружаются
1. Проверьте размер файлов (максимум 5MB)
2. Убедитесь, что выбранные файлы являются изображениями
3. Проверьте общее количество изображений (максимум 50)

### JavaScript не работает
1. Убедитесь, что статические файлы загружаются правильно
2. Проверьте консоль браузера на наличие ошибок
3. Убедитесь, что файлы находятся в правильных папках

### Стили не применяются
1. Проверьте, что CSS файлы загружаются
2. Убедитесь, что файлы находятся в staticfiles для продакшена
3. Выполните `python manage.py collectstatic` для обновления статических файлов

### Быстрая загрузка галереи отеля
1. Подготовьте изображения отеля в отдельной папке
2. Найдите секцию "Загрузка нескольких изображений" в верхней части страницы
